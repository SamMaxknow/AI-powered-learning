# AI 学习法 v0.1.0 Skill

> 本 Skill 是基于爱AI的大刘的版权作品《用Claude、Codex、Workbuddy 10倍速学习任何知识（轻科技）》所载十步学习法的改进版。原方法版权归原作者所有，在此致谢。

一个可直接装进 AI Agent 的学习方法 Skill：用一条闭环流程快速进入任何陌生知识领域。

## 这是什么

第 0–11 步的完整学习闭环：定标 → 五视角调研 → 矛盾图谱 → 资源基线 → 综合简报 → 核查清单 → 学习阶梯 → 核心 20% → 考官考试/技能实作 → 费曼循环 → 一页速查表 → 延迟复测（第 3 天、第 7 天）。

相比常见的"问 AI 要总结"，这套方法的关键增量在三处：

- **防幻觉闸口**：简报中的事实断言要逐条核查，查无此事的直接删除，证据分等级标注；
- **双轨考核**：知识型主题用主动回忆考试，技能型主题用真实作品验收，不拿"知道"冒充"会做"；
- **延迟复测**：学完不算数，3 天和 7 天后复测留存，才标记"已掌握"。

支持三档：轻量版（约 2 小时）、标准版（半天）、完整版（深耕领域）。

## 使用方法

把本仓库的 `SKILL.md` 与 `references/method.md` 放进你的 Agent 的 skills 目录（或让 Agent 直接阅读本仓库），然后对它说：

> 用学习法学【主题】

Agent 会自动分档分轨推进：调研、简报、核查、题库、速查表由它完成，只在定标、考试、费曼复述三处需要你本人参与。

## 文件

- `SKILL.md` — 执行协议：入口、分工、状态管理、复测安排
- `references/method.md` — 方法论全文：第 0–11 步的目的、做法与可直接复制的提示词
